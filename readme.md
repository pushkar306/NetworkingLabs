# Networking Labs

This repository documents my practical journey in learning computer networking through hands-on labs and experiments.

The focus is on understanding networking concepts by implementing them, analyzing the results, documenting observations, and recording the reasoning behind each implementation.

Each session is self-contained and represents a milestone in my learning rather than just a collection of classroom exercises.

The repository is intended as a long-term learning journal and will grow alongside my networking and cybersecurity journey.
